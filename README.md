# buddies-sandbox

A test bed for [laazyj/buddies](https://github.com/laazyj/buddies). It has deliberately
outdated dependencies so Dependabot keeps opening PRs, and the same branch rules as the
real repositories (PR required, required checks up to date, CodeQL), so buddies can take
**live** actions here before they're trusted anywhere else.

Nothing here matters: merge, close or reset freely.
